# معرفی فارسی NOVA Motion Studio

- مدت:30ثانیه،900فریم در30FPS.
- خروجی اصلی: `nova-intro-fa.mp4`، عمودی1080×1920،H.264/AAC.
- محتوا: تیترهای فارسی قابل ویرایش، پنج اسکرین‌شات واقعی برنامه، بخشی از رندر سه‌بعدی خود برنامه و موسیقی اختصاصی.
- این نسخه متن فارسی و موسیقی دارد؛ گوینده ندارد.

پروژه با نام **NOVA — معرفی فارسی اپ** در Studio ذخیره شده است. از بخش Projects آن را باز کنید. متن‌ها، تصاویر، زمان‌بندی، حرکت و صدا لایه‌های معمول پروژه‌اند. `project.json` همان مدل ذخیره‌شده است. برای جابه‌جایی به نصب دیگر، از نسخه ZIP همراه خروجی استفاده کنید؛ JSON تنها، بایت فایل‌های رسانه‌ای را در خود ندارد.

## منابع واقعی

اسکرین‌شات‌ها در `screenshots/` مستقیماً از پنجره1280×720 مرورگر، بدون نوار آدرس و تب‌ها، ذخیره شده‌اند. تصاویر رابط کاربری تولید یا بازنقاشی نشده‌اند. فقط در ترکیب‌بندی ویدیو، جابه‌جایی، زوم، چرخش و برش قاب روی خود تصاویر اعمال می‌شود.

- `editor.jpg`: ادیتور، تایم‌لاین و پروژه واقعی فارسی.
- `templates.jpg`: صفحه12قالب داخلی برنامه.
- `three-editor.jpg`: پیش‌نمایش واقعی سه‌بعدی همراه تنظیمات دوربین.
- `director.jpg`: پنلDirector با توضیح اتصالMCP؛ نبود اتصالAI داخلی در تصویر پنهان نشده است. ادعای متن مربوط به اتصال ایجنت از طریقMCP است.
- `export.jpg`: پنجره واقعی خروجیMP4؛ تصویر پیشرفت یا تکمیل ساختگی نمایش داده نمی‌شود.

نمای سه‌بعدی متحرک از `examples/output/persian-business-reel.mp4`، ساخته‌شده با خودNOVA، گرفته شده است. `nova-intro-original-score.wav` در همین تولید با نوسان‌سازهای صوتی و نویز دانه‌دار ساخته شده است؛ آهنگ تجاری یا صدای فرد دیگری استفاده نشده است.

`storyboard.json` زمان‌بندی و منبع هر نما، `frames/` هفت فریم بررسی، و `contact-sheet.png` نمای کنارهم صحنه‌ها را نگه می‌دارند. گزارش نهایی renderer در `nova-intro-fa.mp4.metadata.json` شناسه واقعی کار، تنظیمات و اطلاعاتFFprobe را ثبت می‌کند.

## بازتولید

از ریشه پروژه، پس از `npm run dev`:

```bash
node --import tsx scripts/create-nova-intro.ts
node --import tsx scripts/render-nova-intro.ts --review
node --import tsx scripts/render-nova-intro.ts --final
```

تصاویر اصلی و متن‌های قابل ویرایش در این پوشه باقی می‌مانند. مرحله ساخت، پروژه اختصاصی همین ویدیو را به‌روزرسانی می‌کند و پروژه‌های دیگر را تغییر نمی‌دهد.
